Tasks for Windows 0.87.0

Install over the existing version. Tasks, theme, pairing and taskbar identity are
retained. Open your current phone with Android Tasks 0.87.0 first and wait for
Settings > Google sync to say Synced with Google. That phone initializes the cloud
list; other clients restore it instead of importing their old task lists.

Google setup on Windows:
1. Open https://console.cloud.google.com/auth/clients and select Tasks.
2. Download the JSON for the Windows Desktop app client. If necessary create a
   Desktop app client in the same project, then download its JSON.
3. In Tasks choose Settings > Google sync > Set up Google and select that file.
4. Sign into the same account as the phone. Your cloud tasks restore automatically.

The JSON contains the client secret Google requires for desktop token exchange.
It and your refresh token are encrypted with Windows DPAPI. Do not send the file
through chat. Once connected, the account row has an X to remove it, plus Sync now.
Old local task data is backed up privately before first cloud restore. Deleted
tasks remain deleted across clients; offline changes merge after reconnection.

Tasks supports adding/editing tasks, Today/Upcoming, projects (hold the date at
the top), priorities, labels, recurrence, notes, checklists, completion/progress,
ordering, history/trash and theme settings. Local QR pairing remains available.
Android reminder and widget controls remain phone features.

Closing the window keeps PC sync running. Reopen from the same shortcut. Updates
and uninstall retain private data in %LOCALAPPDATA%\Tasks. Backup copies made
before cloud restores are under its cloud-backups directory.

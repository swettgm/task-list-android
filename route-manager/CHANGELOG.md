# Changelog

## 1.0.2

- Added Monthly alongside Weekly and Biweekly for saved stops. All notes remain visible.
- Manage stops and stop editors identify the route and weekday. Same-named stops on different routes keep separate frequencies and notes.

## 1.0.1

- Compact Add note editor with a one-line note field that grows with text, intact field labels and safe keyboard-height scrolling.
- Matched the Tasks settings icon, removed the main stop filter/Stops button and moved stop management into Settings.

## 1.0.0

- Separate Route Manager app with five looping route pages and automatic weekday selection.
- Saved-stop autocomplete, disk save button and notes associated with one or more stops.
- Weekly/Biweekly labels without hiding notes.
- Note and stop editing, confirmed deletion, clickable web links and appearance settings.
